# ExamRescue - 試験前夜の駆け込み寺 ⚡

> **「試験が明日なのに、資料が多すぎて覚えきれない…！」**  
> そんなピンチを救う、試験前夜特化型の高速暗記Webアプリケーションです。  
> 手元の講義プリントやPDFをAIに渡すだけで、**あなた専用の4択・用語暗記問題**が自動生成され、爆速で頭に叩き込めます。

---

## 🔰 初めての方へ：3分でできる超かんたん導入ガイド

プログラミングやGitHubに詳しくない方でも、以下の手順通りに進めればすぐに自分のパソコンで動かせます！

### STEP 1: パソコンの準備（最初の一度だけ）
本アプリを動かすための無料ソフト **Node.js** をインストールします。
1. [Node.js 公式サイト (nodejs.org)](https://nodejs.org/) を開きます。
2. 左側の **「LTS（推奨版）」** ボタンを押してインストーラーをダウンロードします。
3. ダウンロードしたファイルを開き、基本的にすべて「Next（次へ）」を押してインストールを完了させてください。

### STEP 2: アプリをダウンロードする
お好きな方法で本アプリをダウンロードします：

- **かんたん方法（ZIPでダウンロード）**:
  1. このGitHubページの上部にある緑色の **「Code」** ボタンをクリックします。
  2. **「Download ZIP」** を選びます。
  3. ダウンロードされたZIPファイルを右クリックし、「すべて展開（解凍）」します。

- **Gitを使える方**:
  ```bash
  git clone https://github.com/LovelySlime/ExamRescue.git
  cd ExamRescue
  ```

### STEP 3: 起動する（コマンドを2回打つだけ！）
1. 展開したフォルダを開きます。
2. フォルダ内の余白（何もないところ）で右クリックし、**「ターミナルで開く」**（または「PowerShell を開く」）を選択します。
3. 開いた黒い画面に、以下のコマンドを1行ずつコピー＆ペーストして `Enter` キーを押します：

```bash
# ① 必要な部品を準備します（初回のみ、数十秒で終わります）
npm install

# ② アプリを起動します！
npm run dev
```

4. 画面に `http://localhost:5173` と表示されたら、ブラウザ（ChromeやEdgeなど）でそのアドレスを開きます。  
   🎉 **これでお試し用サンプル問題が起動し、すぐに学習を始められます！**

## 📖 どうやって使うの？（2つの学習スタイル）

### スタイルA: いつものAI（ChatGPTやClaude）を使う【手軽でおすすめ】
1. 画面右上にある **「AIプロンプト」** ボタンを押し、指示文をワンクリックでコピーします。
2. ChatGPT や Claude などの画面に、コピーした指示文と **手元の講義レジュメやPDF** を一緒に貼り付けて送信します。
3. AIが作ってくれた問題データ（JSON形式のテキスト）をコピーします。
4. 画面右上にある **「JSON読込」** ボタンを押し、貼り付けて「読み込む」を押すだけ！  
   あなた専用の試験特訓が即座にスタートします。

### スタイルB: ローカルAIエージェント（Cursor, Antigravity等）と共闘【完全全自動】
1. 本フォルダをエージェントに開かせます。
2. 試験資料を渡して「この資料から頻出問題を作って（AGENT_INSTRUCTIONS.md 参照）」と伝えるだけで、自動的に問題ファイル（`data/questions.json`）が生成されます。
3. 解き終わると結果（`data/results.json`）が自動保存されるので、AIに「間違えた問題の直前チートシートを作って」と頼むだけで、試験直前5分で読める神まとめが完成します！

## ✨ ここがすごい！試験前夜に特化した便利機能

### 1. 「場所で覚える」を防ぐシャッフル ＆ メモの並び順記憶
- 何回も解いていると、「内容は覚えてないけど、たしか2番が正解だった気がする…」と場所で覚えてしまいがちです。ExamRescueでは**毎回選択肢の順番をランダムに入れ替え**て本質的な記憶を促します。
- **安心ポイント**: 解答中に「1番は消去法で消えるから3番にした」と思考メモを残した場合でも、**「その時に何番がどの選択肢だったか」をシステムが自動で記録**しています。後から見直したときに「あれ、この時1番ってどの選択肢のことだったっけ？」と混乱することが絶対にありません。

### 2. 自分だけの「語呂合わせ・覚え方」をその場でメモ
- 他人の解説を眺めるより、「自分が思いついたこじつけや語呂合わせ」のほうが100倍記憶に残ります。
- 答え合わせ画面ですぐにメモを書き込めるため、学習後に「自分だけの弱点・語呂合わせ集」を振り返ることができます。

### 3. 用語問題の「ちょっとした打ち間違い」を賢く判定
- 用語の穴埋め問題で、「キャッシュメモリ」と打つべきところを「キャッシュ」と略したり、カタカナ・ひらがな、大文字・小文字、軽微なタイプミスがあっても、アプリが「ほぼ合っています！」と柔軟に○判定を提案してくれます（もちろん自分で×に修正も可能）。

### 4. 途中で寝落ちしても安心！自動セーブ ＆ 途中再開
- 1問解くごとに自動で進行状況が保存されます。
- 万が一ブラウザを閉じたり、眠気に負けて翌朝続きをやることになっても、トップ画面の **「中断した特訓を途中から再開」** からワンタップで元の問題に戻れます。

### 5. 「間違えた問題だけ」を何度も叩き込む集中ループ
- 全問終了後、またはトップ画面から **「直前に間違えた問題だけを再特訓」** が選べます。
- 不安な弱点だけをピンポイントで何度も周回し、本番までに正答率100%へ持っていけます。

### 6. キーボードだけでサクサク進む爆速操作
- マウス操作は不要です。
  - 数字キー `[1]` 〜 `[4]` : 選択肢を選ぶ
  - `[Enter]` : 答え合わせ ➔ 次の問題へ進む
- 画面遷移時にEnterキーを押しすぎて次の問題まで勝手にスキップしてしまわないよう、**「キーを一度離してから押し直した時だけ進む」安全設計（エッジトリガー検知）**を搭載しています。

## 🔒 著作権・個人情報の安心保護
大学や学校の講義レジュメ、過去問PDF、個人的な解答データは、Git管理から完全に除外（`.gitignore`）されています。  
**誤ってあなたの個人データや著作権のある資料がインターネット（GitHub）上に公開される心配はありません**。

---

## ⌨️ キーボード操作一覧

| キー | 動作 |
| :--- | :--- |
| **`[1]` 〜 `[4]`** | 選択肢を選ぶ（4択問題） |
| **`[Enter]`** | 解答を確定 ➔ 答え合わせ ➔ 次の問題へ進む |
| **`[Esc]`** | 開いているポップアップ（モーダル）を閉じる |
