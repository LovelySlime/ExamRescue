**試験が明日に迫った学生のための、包括的かつ極限最適化された学習Webアプリケーションです。**  
手元の資料（レジュメ・PDF・講義ノート）からローカルAIエージェントが瞬時に問題データを生成し、**「JSONコピペ摩擦ゼロ」**で超高速・高定着の学習ループを回せます。

---

## 🎯 開発の背景と3つのコア学習原則（勉強のプロ視点）

「試験前夜」において最も貴重なリソースは**「時間」**と**「ワーキングメモリ」**です。  
単なる受け身の眺め読みや、当てずっぽうの丸暗記を徹底排除し、最短時間で合格点へ引き上げる認知科学的アプローチを採用しています。

```mermaid
flowchart TD
    subgraph ゼロ・フリクション 学習サイクル
        A[試験資料 レジュメ・PDF] --> B[ローカルAIエージェントが data/questions.json を生成]
        B --> C[npm run dev でWebサーバー起動]
        C --> D[ブラウザで高速特訓 4択・用語想起]
        D --> E[data/results.json に自動保存 手作業ゼロ]
        E --> F[AIが自作語呂合わせ入りの直前神チートシートを生成]
    end
```

1. **解答根拠のアウトプット（自己説明効果）**:
   「たまたま正解」を排除。「語呂合わせ：〇〇」「消去法で2番以外ない」など、なぜそれを選んだかを言語化して記憶を強固に定着させます。
2. **1問ごとの即時答え合わせ（記憶の上書き）**:
   誤った記憶を1分も放置せず、直後にAIの模範根拠と突き合わせて正しい知識で脳内を上書きします。
3. **自分用覚え方・語呂合わせメモ（自己関連付け効果）**:
   他人の解説より「自分にとって身近な文脈のこじつけ」が最強の暗記手段。思いついたメモは `results.json` に蓄積され、直前チートシートに集約されます。

## ✨ 主要機能ハイライト

- 🎲 **選択肢の完全ランダムシャッフル ＆ 出題順トレーサビリティ**:
  選択肢の並び順で覚えてしまう擬似記憶を防止。ユーザーが「2番は〜〜だから1番」とメモした場合でも、その時の出題順（`presentedOptions`）と選択番号を完全記録するため、AIや自分の見返し時に推論が迷子になりません。
- ✍️ **用語想起モード（インテリジェント表記ゆれ判定）**:
  全角半角、ひらがな/カタカナ、大文字小文字、軽微なタイポ（レーベンシュタイン距離）を吸収し、ほぼ合っていればデフォルトで「○ 正解」サジェスト。ワンタップで修正可能。
- ⚡ **オートセーブ ＆ 1クリック再開（中断リカバリー）**:
  1問解くごとに自動保存。途中でブラウザを閉じたり翌朝再開した時でも、トップ画面から「中断した特訓を途中から再開」できます。
- 🔁 **弱点潰し込みループ（間違えた問題のみ再特訓）**:
  全問終了後、またはトップ画面から「直前に間違えた問題（X問）のみ再特訓」をワンクリックで起動可能。
- 📜 **過去の特訓履歴管理**:
  過去の各回の正答率推移や全問の○×状況をいつでもモーダルで確認・再特訓可能。
- 🖥️ **完全シングルスクリーン（ノー・スクロール）UI**:
  一般的なPC画面比率（16:9 / 16:10）で上下左右のスクロールが一切発生しない快適設計。

## 🚀 使い方ガイド

### モードA: ローカルAIエージェントと共闘（推奨・摩擦ゼロ）

ローカル環境のAIエージェント（Antigravity, Cursor, Claude Code, Aider等）に本リポジトリを開かせます。

1. **問題生成を指示**:
   試験資料（PDFやレジュメ）を渡し、以下のように伝えます：
   > 「この資料から頻出ポイントを抽出して `data/questions.json` を作成してください（仕様は AGENT_INSTRUCTIONS.md 参照）」
2. **サーバー起動**:
   ```bash
   npm run dev
   ```
3. **特訓開始**:
   ブラウザで [http://localhost:5173](http://localhost:5173) を開き、問題を解きます。
4. **自動保存 ＆ チートシート生成**:
   全問解き終わると自動で `data/results.json` に結果が保存されます。エージェントに「直前チートシートを作って」と頼むだけで、あなたの自作語呂合わせを盛り込んだまとめが即座に出力されます。

---

### モードB: Webアプリ単体で使う（手動モード）

1. 画面右上の **「AIプロンプト」** ボタンを押し、プロンプトをワンクリックコピー。
2. ChatGPTやClaudeに試験資料と一緒に貼り付けてJSONを出力。
3. 画面右上の **「JSON読込」** ボタンに貼り付けてスタート。

## ⌨️ キーボード爆速ショートカット

| キー | アクション |
| :--- | :--- |
| **`[1]` 〜 `[4]`** | 4択の選択肢を選ぶ |
| **`[Enter]`** | 解答確定 ➔ 即時答え合わせ ➔ 次の問題へ進む |

※ 画面遷移時のEnter連打による誤スキップを防ぐ**エッジトリガー検知（立ち上がり検知）**を搭載しています。

## 🛠️ インストール ＆ 開発起動

```bash
# 1. クローン
git clone git@github.com:LovelySlime/ExamRescue.git
cd ExamRescue

# 2. 依存関係のインストール
npm install

# 3. 開発サーバーの起動 (自動でローカルAPIも有効化)
npm run dev

# 4. ブラウザでアクセス
# http://localhost:5173
```

## 🔒 プライバシー ＆ 著作権保護

学校や大学の講義レジュメ、過去問PDF、個人的な解答記録は `.gitignore` に指定されており、**Gitリポジトリに機密情報・著作権物がコミットされることはありません**。  
クローン直後は著作権フリーなサンプルデータ（`data/questions.sample.json`）で安全に動作確認できます。
